About Grow Up Group

Grow Upグループの目的

Grow Upグループは、「Grow Up Academy」「レンディル浜松スポーツクラブ」「しずおかコネクト」の3つの団体が力を合わせて生まれた、地域と次世代を育てる総合プラットフォームです。

教育・スポーツ・学生支援という異なる得意分野を持ち寄り、
“浜松から未来を切り拓く人を育てること” を目的に活動しています。

Grow Up Academyが教育で土台をつくり、
レンディル浜松がその力を現場で活かし、
しずおかコネクトが人と地域をつなぐ。

この循環を仕組みとして整えることで、「教育 → 実践 → 地域貢献」の流れを自然に生み出しています。

各団体の役割

Grow Up Academy（教育・人材育成）

Grow Up Academyは、グループの中で最も「教育」と「育成」に特化した組織です。

  • ✔ 指導法・教育ノウハウを活かした人材育成プログラムや企業研修を実施
  • ✔ レンディル浜松の現場へ教育メソッドを導入し、指導の質向上や育成システムづくりを担当
  • ✔ しずおかコネクトと連携して、研修 → 実践 → 活躍の流れを設計
📌 特徴：教育の品質保証と指導体系の中心

レンディル浜松スポーツクラブ（実践・地域連携）

レンディル浜松は、スポーツや文化活動を通じて、学びを“実際の体験”につなげるフィールドを提供しています。

  • ✔ 子どもから大人まで参加できるスポーツ・文化の場を運営
  • ✔ 部活動移行先や地域クラブの指導者を登録・派遣し、地域の指導者マネジメントを担当
  • ✔ Academyで学んだ教育メソッドを現場に導入し、チーム運営や地域イベントまで幅広くサポート
📌 特徴：地域に一番近い「現場力」が強み

しずおかコネクト（学生マッチング・地域ネットワーク）

しずおかコネクトは、学生 × 地域企業 × 団体をつなぐネットワークハブとして機能しています。

  • ✔ 学生を発掘し、企業・団体へつなげるマッチングの専門家
  • ✔ Grow Up Academyの教育を学生に接続し、即戦力として活躍できる力を育成
  • ✔ レンディル浜松の現場やイベントを、学生が挑戦できる実践の場として提供
  • ✔ 地域企業のCSR活動や産学連携もサポート
📌 特徴：人と地域をつなぐ「接続力」が武器
